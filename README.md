# coolest-art-01-entry

My entry for make.fun's **coolest-art-01**: "Galaxy Koi over Moonlit Waves" — a
colossal koi made of galaxies and nebulae, swimming over moonlit ocean waves.

`main.ts` (Node, standard library only) delivers the bundled artwork
(`entry.png`, JPEG bytes, 1024x683) to the grader's `/output/entry.png`,
after checking it against the gate's 1 MiB cap and image format.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
